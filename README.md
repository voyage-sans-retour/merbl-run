# Merbl Run

<img src="https://file.garden/ao48rmQtA0WCEInu/Screenshot%202026-10-18%20214250.png" width="400" height="400">
A cool 3d printable track for a marble (and it comes with the marble too!)

the marble will start at the top, then swirl around in a helix path, tumble down a staircase, ricochet through a plinko path, and finally fall down to the base where it will be prevented from rolling away. this track is my first attempt at using cad!
